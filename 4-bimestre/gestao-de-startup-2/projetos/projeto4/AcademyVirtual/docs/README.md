
# 🎓 AcademyVirtual

## Sobre o projeto

O AcademyVirtual é uma plataforma de ensino virtual desenvolvida para facilitar o acesso à educação.

O sistema permite organizar conteúdos, acompanhar aulas e atividades e facilitar a comunicação entre alunos e professores.

## Objetivo

Criar uma plataforma simples, organizada e acessível para auxiliar no aprendizado.

## Funcionalidades
- Cadastro de alunos
- Cadastro de professores
- Acesso às aulas
- Organização de cursos
- Atividades escolares
- Acompanhamento do aprendizado

## Tecnologias
- HTML
- CSS
- JavaScript
