
# 📘 Manual de Operação — AcademyVirtual

## 1. Como trabalhamos

### Como as tarefas chegam até a equipe?

As tarefas são definidas de acordo com as atividades solicitadas pelo professor. A equipe analisa o que precisa ser desenvolvido e anota as funcionalidades necessárias para o AcademyVirtual.

### Como decidimos quem faz o quê?

As tarefas são divididas entre os integrantes conforme suas habilidades e conhecimentos. Quando alguém termina sua parte, avisa aos outros integrantes para que o projeto continue.

### Como sabemos que uma tarefa está pronta?

Uma tarefa está pronta quando:

- [ ] O código está funcionando.
- [ ] Não apresenta erros.
- [ ] A funcionalidade foi testada.
- [ ] O visual está organizado.
- [ ] A documentação foi atualizada.
- [ ] Outro integrante revisou o resultado.

### O que fazemos quando alguém trava?

Quando alguém encontra dificuldade, explica o problema no grupo da equipe, informa o que já tentou e pede ajuda. Se ninguém conseguir resolver, solicita orientação ao professor.

## 2. Combinados de comunicação

| Combinado | Acordo da equipe |
|---|---|
| Tempo de resposta | Responder quando visualizar, preferencialmente no mesmo dia. |
| Horário de descanso | Ninguém precisa responder fora do horário combinado de trabalho. |
| Canal de comunicação | WhatsApp para conversas e GitHub para códigos e documentação. |
| Urgência | Erros que impedem o funcionamento ou a entrega do projeto. |

### Modelo de pedido de ajuda

1. O que eu quero fazer?
2. O que está acontecendo?
3. Onde está o problema?
4. O que eu já tentei?
5. O que eu preciso de você?

### Modelo de atualização

**ONTEM:** atividades realizadas.

**HOJE:** atividades que serão feitas.

**TRAVADO:** dificuldades encontradas.
