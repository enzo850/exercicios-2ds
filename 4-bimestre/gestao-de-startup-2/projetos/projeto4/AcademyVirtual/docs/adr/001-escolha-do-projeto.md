
# ADR 001 — Escolha do AcademyVirtual

**Data:** 25/11/2026

**Status:** Aceita

## Contexto

A equipe precisava escolher um produto para desenvolver durante as atividades escolares. Surgiu a ideia de criar uma plataforma de ensino virtual que facilitasse o acesso dos alunos aos conteúdos e atividades escolares.

## Decisão

A equipe decidiu desenvolver o AcademyVirtual, uma plataforma de ensino virtual com funcionalidades para alunos e professores.

## Consequências

### Positivas
+ O projeto pode ajudar na organização dos estudos.
+ Permite desenvolver diferentes funcionalidades.
+ Ajuda a equipe a praticar programação.

### Negativas
- O desenvolvimento pode exigir bastante tempo.
- Algumas funcionalidades podem ser difíceis de implementar.
- Será necessário testar e corrigir erros frequentemente.
